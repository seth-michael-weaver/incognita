    An explorable explanation of the INCOGNITA reaction engine

    Inside a Nuclear Reaction

    One neutron. One nucleus. Many ways for it to end.

    Click or tap anywhere to fire your own neutron.

    Scroll to begin ↓

    Fire a neutron at an atomic nucleus and something comes back out. It might be the neutron itself, bounced off. It might be a proton, an alpha particle (a tight cluster of 2 protons and 2 neutrons), or a burst of light. A heavy nucleus might even split in two.

    Which one happens, and how often? This page walks through how our software answers that question, one step at a time. Scroll down, and try the controls along the way. Every animation runs on the same physics as the real code.

    Where this lives in the code

    Each stage above is a package in physics/hf, and the engine calls them in the order you just read. Out of the box the engine reproduces TALYS-2.x, the established reaction code it was ported from. The physics it adds sits behind named switches inside the same packages, all off by default, so turning one on changes exactly one thing.

    Each of these is a switch, off unless set, so a default run still matches TALYS.

    Outside the engine

    Two parts of the story run beside the engine rather than inside it. The statistical resonance ladders of Chapter 10 live in physics/resonance/. The stellar averages of Chapter 11 are taken after the run from the engine's capture curves, in validation/differential/core.py. The engine does not compute angular distributions or reactions on thermally excited targets.
