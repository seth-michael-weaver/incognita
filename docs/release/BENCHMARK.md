# The INCOGNITA open benchmark (v0.1) and the prospective registry

An open, frozen set of measured points on which any evaluation (ENDF/B, JENDL, JEFF, TENDL, BROND, CENDL, FENDL,
IRDFF, BRUSLIB, ours, yours) is scored the same way, plus a hash-chained registry of predictions made before the
measurements exist. Full tables: generated by `uv run python -m incognita.bench.score leaderboard` from libraries you stage (not distributed here, because they contain scores computed on library files we do not redistribute). Track data
cards: [`incognita/bench/tracks/README.md`](../../incognita/bench/tracks/README.md). Registry:
[`docs/registry/SUBMIT.md`](../registry/SUBMIT.md).

Metric everywhere: rms of log10(prediction / measurement), in dex (0.1 dex ≈ 26 %). Brackets are 95 % nucleus-bootstrap
intervals; Δ is a paired difference on the rows both entries cover (negative = the first entry is better).

## Where we lose (read this first)

1. **Capture on nuclei held out of our fit: every major evaluated library beats INCOGNITA.** The shipped model, on the
   development folds 0–5 (1,947 cells, 122 nuclei): JENDL-5 0.137, ENDF/B-VIII.1 0.143, TENDL-2025 0.147, against ours
   0.1765 (D0 withheld) and 0.1569 (measured D0 used). Ours − ENDF/B-VIII.1 = +0.034 [+0.011, +0.059]; ours − TENDL-2025 =
   +0.030 [+0.008, +0.055]; ours − JENDL-5 = +0.039 [+0.015, +0.065]. The libraries are not blind on this track: their
   evaluators fitted these measurements. We are. The only rival that is blind here too is default TALYS (TENDL's no-data
   recipe, run by our engine): ours 0.1765 vs 0.1898, Δ −0.0133 [−0.0229, −0.0035]. On the sealed reserve (folds 6–7,
   read once) that difference is a tie, −0.0055 [−0.021, +0.010] (README).
2. **(n,α) measured after JENDL-5** (116 points, 12 nuclei): our frozen v2 0.222 vs JENDL-5 0.137, Δ +0.085
   [+0.022, +0.164]. The best entry is BROND-3.1 (0.134), then JENDL-5.
3. **He production and (n,α) total**: JENDL-5 beats the v1 recipe on the rows a library file covers: 0.162 vs 0.234,
   Δ +0.072 [+0.034, +0.109] (142 rows); (n,α) total 0.204 vs 0.311, Δ +0.107 [−0.012, +0.201] (55 rows).
4. **No structure data**: the shipped value (the recipe with our E1 constant) 0.2101 vs default TALYS 0.2042, Δ +0.0059
   [−0.0025, +0.0140], a tie; below 10 keV worse. With nothing known about a nucleus, we ship the recipe.
5. **The four in-sample channel tracks and the SACS track have no INCOGNITA entry.** The v5 evaluation that used to sit
   there is the 9-library median (INDEP_AUDIT) and is retracted. They are published as a library-vs-library benchmark.

## Dated tracks (added 2026-09-23, DATEDEXAM)

Every library is scored only on EXFOR rows published and compiled after its release year, and our arms are trained on
data up to that year: `dated-2006` to `dated-2024`, 7 channels. Leaderboard: generated the same way (not distributed in this preview).
The full write-up of the dated exam is not part of this preview. In short, the registered overall lines favour us
by 0.1-0.3 dex, but that is a placement artifact below 100 keV. Libraries that fitted these rows score just as badly
there. Above 100 keV, DEFD (default TALYS port + defect GP, trained on pre-release data) **ties every library**: every
95 % CI contains zero (e.g. vs ENDF/B-VII.1 −0.010 [−0.035, +0.015], 140 nuclei). JEFF-4.0 and TENDL-2025 have no
post-release rows yet.

## The tracks, and what publishing them spends

Twelve tracks, 19,873 rows (the two capture-heldout-based tracks share cells), cut from frozen files whose sha256 the scorer checks before it runs. **All twelve are
retired from our internal model selection at publication** (2026-09-27), including folds 6-7 of the capture exam (the
internal vault, already spent on 2026-09-22) and the 48 TERRA-RESERVE nuclei it contains (read on 2026-09-23). From the
release on, our held-out data are (a) the prospective registries and (b) EXFOR entries added after the 2026-09-09
snapshot. The 674/669-bin blind protocol is not a track and was not scored here, but it shares (nucleus, bin) cells with
`capture-heldout` (targets defined differently: post-2012 data only), so once the exam file is public it can no longer be
treated as unseen: we recommend retiring it too.

Not published: MACS tracks (KADoNiS / ASTRAL labels: redistribution terms not verified), the stock-control rows
(an engine-fidelity check, not a benchmark), and the tier-coverage rows (our own residuals, no labels).

## Scoring any evaluation

```bash
python -m incognita.bench.score tracks                                    # list, verify source hashes
python -m incognita.bench.score export --track all --out rows/            # the public row tables (also in incognita/bench/tracks/rows)
python -m incognita.bench.score score --track all --csv mine.csv --name "my model"   # columns track,row,value_b[,h68,h95]
python -m incognita.bench.score score --track all --endf DIR --njoy $(which njoy) --name "my library"   # ENDF-6 files
python -m incognita.bench.score leaderboard --out docs/release/bench      # everything above, from staged library grids
```

A CSV may carry 68 / 95 % half-widths (log10); the scorer then reports coverage. ENDF-6 files are reconstructed with
NJOY2016 RECONR (0.1 %), sampled on the 3000-point grid and interpolated log-log at each row energy, which is the rule
the development tree used for every library number (`incognita/eval/hydrate.py`).
